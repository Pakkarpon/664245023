# Portfolio — นายพรรคพล พูลสวัสดิ์

หน้าเว็บ Portfolio แบบ HTML/CSS ธีมพื้นหลังกรมท่า-ม่วง พร้อมสีเขียวอมฟ้า แตกต่างจากตัวอย่าง และเชื่อมลิงก์งานที่ได้รับจากเจ้าของผลงาน

## วิธีใช้
1. แตกไฟล์ ZIP
2. เปิด `index.html` ในเบราว์เซอร์เพื่อตรวจสอบหน้าตา (ต้องวางไฟล์ `Top1.jpg` ไว้โฟลเดอร์เดียวกับ `index.html`)
3. อัปโหลด `index.html` และ `Top1.jpg` ไปยัง Repository สำหรับ Portfolio บน GitHub
4. เปิด Settings → Pages
5. เลือก Build and deployment: **Deploy from a branch**
6. เลือก Branch `main`, Folder `/(root)` แล้วกด Save
7. เมื่อ GitHub Pages เผยแพร่เสร็จ ให้ใช้ URL ที่แสดงในหน้า Settings → Pages ส่งอาจารย์

คู่มือ GitHub Pages:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
